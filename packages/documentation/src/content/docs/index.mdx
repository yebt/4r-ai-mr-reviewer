## What is 4R?

4R runs AI code review over your **GitLab merge requests**, entirely on your own
infrastructure. You configure a GitLab account and an AI provider, track a
repository, and launch a review on any open MR. The engine loads the **4R rule
sets**, sends the diff to the model, and returns **located, structured findings**
with a **deterministic score** and an approve / request-changes recommendation.
You then choose which findings to publish back as inline discussions — optionally
rewritten in your own voice.

Usable, **single-user, GitLab-first**. The core loop (configure → review →

and release routines all ship today. GitHub support and webhook auto-triggering
are on the roadmap.
